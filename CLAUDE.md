Read `AGENTS.md` for the conventions shared by every agent working in this repository.

Project skill: `/experiment-analyze-explain` (`.claude/skills/experiment-analyze-explain/SKILL.md`)
diagnoses an ML result with a fixed set of measurements, decides what to scale, records it, and
explains the chain to a new intern. Use it when a run underperforms, a result surprises you, or
the user asks why or what to scale next.
